Remaining risks & recommended next moves

  1. Dependency remediation (priority 0): a current frontend audit reports 37 advisories (1 critical, 14 high, 17 moderate, 5 low). Land a small, pinned upgrade series with the same full V&V matrix; do not use an unreviewed mass auto-fix.
  2. Bounded abuse controls (priority 1): replace the in-memory, attacker-influenced rate-limit map with an edge/trusted-client-IP control and a bounded TTL store before accepting public contact traffic.
  3. Rust rendering chain (priority 1): cargo audit currently allows three transitive advisories through usvg/resvg: unmaintained rustybuzz, unmaintained ttf-parser, and an unsound memmap2 advisory. Upgrade or isolate the renderer in a separately reviewed change.
  4. Release decisions (blocking): resolve the external API host and region choices, contact-storage/retention/deletion policy, production headers (including HSTS after a stable domain), and deployment evidence. These decisions were intentionally not inferred.
  5. Baseline hygiene (priority 2): choose a declared visual-test OS or retain reviewed OS-specific snapshots; clean the 89 formatting diagnostics in a dedicated low-risk formatting PR.
